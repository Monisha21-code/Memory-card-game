# 🧠 Memory Card Game

A fun and interactive Memory Card Game built using **HTML, CSS, and JavaScript**.

The player flips cards, finds matching pairs, earns coins, and receives a bonus reward after completing the game.

## ✨ Features

- 🔐 Login page
- 📝 Sign Up page
- 🏠 Home page
- 🧠 Memory Card Game
- 🪙 Coin and reward system
- 🎮 Games Played counter
- 🏆 Games Won counter
- ⏱️ Game timer
- 🔢 Moves counter
- 🎉 Winning popup
- 👤 Profile page
- 💾 Data saved using Local Storage
- 📱 Responsive design for mobile and desktop

## 🪙 Coin System

The game includes a simple reward system.

- New account starts with **50 coins**
- Correct card match gives **+10 coins**
- Completing all card pairs gives a **+50 bonus**
- Total coins are saved in Local Storage
- Coins are displayed on the Home, Game, and Profile pages

## 🎮 How to Play

1. Create an account using the Sign Up page.
2. Login with your email and password.
3. Go to the **Play Game** page.
4. Click on a card to reveal it.
5. Click another card to find its matching pair.
6. Match all 8 pairs.
7. Earn coins for every correct pair.
8. Complete the game to receive the winning bonus.
9. Check your coins and statistics on the Home or Profile page.
